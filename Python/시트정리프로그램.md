## 엑셀 시트 정리 프로그램 — 수식 대신 파이썬 GUI로

### 문제 배경

RMA 시트의 특정 열을 SYSTEM 시트로 옮기는 반복 작업이 있었다.
기존 방식은 엑셀 수식이었다.

```
=IF(RMA!M3="","",RMA!M3)
```

### 문제

**열 순서와 이름이 자주 바뀐다.**
셀 위치 기반 수식(`RMA!M3`)은 열이 하나만 밀려도 전부 어긋난다.
그때마다 수식을 손으로 다시 잡아야 했다.

### 시도 방법

| 방법 | 판단 |
|---|---|
| 엑셀 매크로(VBA) | 파일마다 매크로를 심어야 하고, 보안 설정에 걸림 |
| **파이썬 독립 프로그램(GUI)** | **채택** — 파일과 분리되고 exe로 배포 가능 |

**핵심 결정: 셀 위치가 아니라 열 이름으로 매칭한다.**
열 순서가 바뀌어도 이름만 같으면 찾아간다.

### 해결 — 최종 기능

**① 원본 시트 설정**
- 엑셀 파일 선택 → 파일 안의 시트 목록이 자동 표시
- 헤더(열 제목) 행 번호 입력 → 그 다음 행부터 데이터로 인식
- "가져올 열"을 **이름(`관리국,SITE`) / 번호(`1,3,5`) / 열 문자(`A,C,E`)** 세 가지로 지정 가능

**② 결과 저장 위치**
- **새 시트 만들기**: 중복 시 자동으로 `_1`, `_2` 부여
- **기존 시트에 이어서 추가**: 기존 헤더 이름과 자동 매칭해서 해당 열 위치에 채움
  - 기존 시트에 없는 새 열은 자동으로 맨 뒤에 추가

**③ 복사 옵션**
- 서식(글자색/배경색/테두리/표시형식) 함께 복사 여부
- 원본이 수식이면 값 대신 **수식 자체**를 복사할지 여부

**④ 미리보기 / 실행 분리**
- **미리보기**: 저장하지 않고 결과를 화면 표로 확인 (엑셀 파일이 열려있어도 항상 가능)
- **실행**: 실제로 원본 파일에 저장 (이때만 엑셀에서 파일을 닫아야 함 — Windows 파일 잠금)

### 겪은 버그 — "기존 시트에 이어서 추가" 시 행이 밀림

**증상**: 이어쓰기를 하면 기존 데이터와 행이 어긋났다.

**원인**: 마지막 행을 찾을 때 **시트 전체를 기준으로** 찾고 있었다.
다른 열에 더 아래까지 데이터가 있으면, 그 아래부터 쓰기 시작해서 빈 줄이 생겼다.

**해결**: **이번에 채우는 열들만 기준으로** 마지막 행을 찾도록 수정.

### 설계에서 잘한 점

**미리보기와 실제 저장이 계산 로직을 공유한다.**

```
compute_result_rows()  ←  미리보기와 실행이 둘 다 호출
        ↓
run_conversion()       ←  여기서만 파일 저장
```

**미리보기 로직만 고쳐도 실제 실행과 어긋날 일이 없다.**
"미리보기에서는 맞는데 실행하면 다르다"는 최악의 버그를 구조적으로 막았다.

### exe 빌드

```powershell
pip install pyinstaller
pyinstaller --onefile --windowed --name "시트정리프로그램" 엑셀_정리_프로그램.py
```

| 옵션 | 의미 |
|---|---|
| `--onefile` | 파일 하나로 압축 |
| `--windowed` | 실행 시 콘솔창 없이 GUI 창만 |

- 결과물: `dist\시트정리프로그램.exe` (약 12MB)
- `build` 폴더, `.spec` 파일은 임시 파일이라 삭제해도 무방
- ⚠️ **백신이 처음 보는 exe를 경고할 수 있다** → 예외 처리 또는 IT 담당자 확인 필요

### 알려진 제약

| 제약 | 내용 |
|---|---|
| 원본 덮어쓰기 | `wb.save(filepath)`로 **원본 파일을 직접 덮어쓴다.** 엑셀에서 파일을 열어둔 채 "실행"하면 저장 시점에 오류 (GUI 안내 문구로 커버 중) |
| 자동 테스트 없음 | 수동 QA에만 의존 |
| 외부 파일 참조 | VLOOKUP으로 다른 파일을 참조하는 열은 미구현 |

### 배운 점

> **디자인 커스터마이징은 전부 되돌렸다.**
> Pretendard/Noto Sans KR 폰트 + 컬러 톤을 적용했다가, 무채색으로 바꿨다가,
> 최종적으로 **기본 tkinter 모습으로 복귀**했다.
>
> 사내 도구는 예뻐 보이는 것보다 **예측 가능하게 동작하는 것**이 우선이고,
> 커스텀 스타일은 OS/버전에 따라 깨질 여지만 늘린다.
