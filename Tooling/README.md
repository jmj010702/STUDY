## 공통 교훈

> **원인을 고쳤는데 증상이 같으면, 고친 것이 실제로 적용되는 경로에 있는지부터 확인한다.**

```
내가 고친 지점  ──?──▶  실제로 실행되는 지점
                 ↑
        캐시 / 빌드 산출물 / 컨테이너 재생성 / 셸 변환이 끼어든다
```
